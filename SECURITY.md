# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly by opening an issue or contacting the maintainers directly.

**Do not disclose security vulnerabilities publicly.**

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.0.x   | Yes       |

## Security Practices

- No secrets or API keys stored in source code
- All API endpoints validate input
- Security headers configured in `vercel.json`
